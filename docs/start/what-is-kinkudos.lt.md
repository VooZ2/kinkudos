# Kas yra KinKudos?

KinKudos yra privati, vienai šeimai skirta savarankiškai diegiama programa. Vaikai atlieka darbus, renka taškus ir prašo prizų, o tėvai peržiūri prašymus ir priima sprendimus.

Programoje nėra reklamų ar integruotos analitikos. Šeimos duomenų bazė, nuotraukos ir prisijungimo duomenys lieka pas instaliacijos administratorių.

```text
Darbas → pateikimas → tėvų sprendimas → taškai → prizas arba tikslas → istorija
```

Kiekvienas taškų pokytis įrašomas į istoriją. Taisymas yra naujas įrašas, o ne slaptas praeities pakeitimas.
