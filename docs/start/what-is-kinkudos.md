# What is KinKudos?

KinKudos is a private, self-hosted app for one family. Children complete tasks, earn points, and request rewards; parents review the requests and decide what happens next.

There are no ads or built-in analytics. The family database, photos, and credentials stay with the installation operator.

```text
Task → submission → parent decision → points → reward or goal → history
```

Every point change is recorded in the activity history. A correction is a new entry, not a hidden edit to the past.
