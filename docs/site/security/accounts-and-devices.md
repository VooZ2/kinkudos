# Accounts and devices

Each parent has a separate password-protected account. Each child has a profile with a four-digit PIN and needs a paired device before profiles are visible.

Use a separate parent account for every adult who needs to make decisions. Do not share passwords. Removing a parent or child deactivates the account or profile while preserving history; the last active parent cannot be removed.

Name paired devices clearly. Revoke one as soon as it is lost or leaves the family. The family administrator can revoke every child device after confirming their password, which requires all devices to be paired again.
