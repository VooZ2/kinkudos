# Backups

The administrator can configure encrypted daily remote copies of the family database and uploaded photos. The page shows the provider, repository, last successful backup, last integrity check, and any reported error.

- Green means the latest successful remote copy is no more than seven days old.
- A copying status means a run is in progress.
- Red or **Attention needed** requires checking the displayed error and storage configuration.

**Back up now** asks for an additional backup; it never restores data. Change storage credentials only when you have the correct values and the repository password stored outside the server. Restoration is a separate administrator operation, and every new configuration should be followed by a restore test.
