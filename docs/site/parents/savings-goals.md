# Savings goals and child suggestions

A savings goal gives one child a visible target. It is not a separate wallet:
it shows progress against the child’s overall balance.

> **For:** Parents and children<br>
> **Result:** A child can track a desired reward without locking points away

## Let a child suggest an idea

In the child space, the child can choose **Suggest a reward or goal** and add a
title, type, suggested cost, and optional emoji. The idea then appears under
**Parents → Home → Pending requests**.

| Parent decision | Result |
| --- | --- |
| Approve a reward idea | Creates a shared catalogue reward. |
| Approve a goal idea | Creates a personal savings goal for that child. |
| Reject | Requires a reason and leaves points unchanged. |

The parent chooses the final point amount; it does not have to match the
child’s suggestion.

## How a goal behaves

The goal’s progress follows the child’s current balance. It does not reserve
or lock points, so approving a reward or applying a correction can change the
progress shown against the goal. Explain this before using a goal as a promise
that points cannot be spent.
