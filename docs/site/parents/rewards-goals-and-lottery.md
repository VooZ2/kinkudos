# Rewards, goals, and scratch tickets

Paths: **Parents → Manage → Rewards** for the reward catalogue, **Parents →
Manage → Goals** for savings goals, and **Parents → Home** for requests and
decisions.

## Rewards

Create a reward with a clear title, point cost, and optional emoji. Children
see active rewards and can request one when their spendable balance and credit
rule allow it.

| Step | What happens |
| --- | --- |
| Child requests a reward | The request appears under **Pending requests**. The child can cancel it while it is pending. |
| Parent approves | KinKudos deducts the recorded cost after checking that the result will not go below the child’s lower balance limit. |
| Parent rejects | No points move. A rejection reason is required so the child can understand the decision. |

Changing a reward’s cost changes future requests only. A pending request keeps
the cost it had when requested.

## Savings goals and suggestions

A child can choose **Suggest a reward or goal**. After a parent approves a
savings-goal proposal, the new goal shows **Choose mode**, which opens **Choose
how to save**, where the child chooses **Use available points** or **Save
separately**.

- **Use available points** counts the positive spendable balance as progress,
  while those points remain available for rewards.
- **Save separately** transfers selected points out of the spendable balance;
  those points are unavailable for rewards until returned or consumed by goal
  completion.
- Only one active goal per child can be the **Current goal** using available
  points.

Read [Savings goals and child suggestions](savings-goals.md) for the complete
goal workflow. It covers adding points, parent-approved completion, deletion,
and returned saved points.

## Credit and reward requests

Each child has an individual lower balance limit, for example `-100`. **Credit**
limits how far a reward can reduce the balance; it is not extra points. New
reward requests pause after half of the available credit is used. Existing
pending requests remain available for a parent decision.

Change the value with **More → Set credit** on the child card or in
**Parents → Settings → Accounts**, under **Child profiles**.

## Scratch tickets

Scratch tickets are optional and should be treated as a family choice, not a
required reward. They are available only when both switches are on:

1. **Settings → Enable scratch tickets** is on for the family; and
2. **Parents → Settings → Accounts**, under **Child profiles**, has **Enable
   scratch tickets for this child** turned on.

The family settings set the ticket price and per-child weekly limit. The week
runs Monday through Sunday. One child can have only one unfinished ticket at a
time.

When a child buys a ticket, KinKudos deducts the configured price and records
it in History. Revealing the ticket produces a preselected positive, negative,
or no-prize outcome; an outcome cannot take the child below the lower balance
limit. Disabling the feature prevents new purchases and reminders but lets an
already-open ticket finish.

### Before a child buys a ticket

The ticket clearly states that it is a game of chance. A completed ticket can
win up to 150 points, return no points, or lose up to 50 points; a loss is
always capped at the child’s lower balance limit. The child must scratch all
nine fields to reveal the result.
