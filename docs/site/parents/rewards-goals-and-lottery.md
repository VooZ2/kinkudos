# Rewards, goals, and scratch tickets

Path: **Parents → Tasks and rewards** for the reward catalogue; **Parents → Home** for requests and decisions.

## Rewards

Create a reward with a clear title, point cost, and optional emoji. Children see active rewards and can request one when their balance and credit rule allow it.

| Step | What happens |
| --- | --- |
| Child requests a reward | The request appears under **Pending requests**. The child can cancel it while it is pending. |
| Parent approves | KinKudos deducts the recorded cost after checking that the result will not go below that child’s credit limit. |
| Parent rejects | No points move. A rejection reason is required so the child can understand the decision. |

Changing a reward’s cost changes future requests only. A pending request keeps the cost it had when requested.

## Savings goals and reward suggestions

A child can select **Suggest a reward or goal** and enter a title, type, suggested cost, and optional emoji. A parent sees it under **Pending requests**.

- Approving a **reward** proposal creates a shared catalogue reward.
- Approving a **goal** creates that child’s personal savings goal.
- The parent chooses the final point amount while approving; it does not have to match the child’s suggestion.
- A savings goal shows progress against the child’s overall balance. It does not reserve or lock points in a separate pot, so approved rewards can still change that progress.
- Rejecting a suggestion requires a reason and does not change the balance.

## Credit and reward requests

Each child has an individual lower balance limit, for example `-100`. A reward approval cannot take that child lower than the limit. To prevent a long queue of requests while credit is already heavily used, new reward requests pause after the child has used half the available credit. Existing pending requests remain available for a parent decision.

Change the limit from the child card’s **Change credit** icon or from **Settings → Child profiles**.

## Scratch tickets

Scratch tickets are optional and should be treated as a family choice, not a required reward. They are available only when both switches are on:

1. **Settings → Enable scratch tickets** is on for the family; and
2. **Settings → Child profiles → Enable scratch tickets for this child** is on.

The family settings set the ticket price and per-child weekly limit. The week runs Monday through Sunday. One child can have only one unfinished ticket at a time.

When a child buys a ticket, KinKudos deducts the configured price and records it in History. Revealing the ticket produces a preselected positive, negative, or no-prize outcome; an outcome can never take the child below their credit limit. Disabling the feature prevents new purchases and reminders but lets an already-open ticket finish.

### Before a child buys a ticket

The ticket clearly states that it is a game of chance. A completed ticket can win up to 150 points, return no points, or lose up to 50 points; a loss is always capped at the child’s credit limit. The child must scratch all nine fields to reveal the result. Consider agreeing on the family rule and price together before enabling the feature.
