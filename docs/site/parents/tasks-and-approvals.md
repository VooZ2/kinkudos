# Tasks and approvals

Parents create a shared task catalogue in **Parents → Tasks and rewards**. Children can choose eligible tasks, or parents can assign a set of tasks for today. Use short titles that describe a finishable result.

When a child submits work, the parent **Home** section shows a pending request.

- **Approve** awards the shown points.
- **Request changes** lets the child revise and submit again.
- **Reject** closes the request without awarding points.

Assigned daily tasks award their points when the child completes them. They are active for that calendar day only. Check **History** when you need to confirm what happened.
