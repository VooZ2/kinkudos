# Leidimų ir palaikymo politika

KinKudos yra bendruomenės projektas, prižiūrimas **pagal galimybes**. Jis
skirtas šeimoms, kurios valdo savo diegimą; tai nėra valdoma hostingo paslauga.

## Kuri versija palaikoma?

Palaikomas tik **naujausias paskelbtas KinKudos leidimas**. Prieš prašydami
pagalbos atnaujinkite KinKudos iki naujausios versijos.

Saugumo pataisos įprastai išleidžiamos tik naujausiai versijai. Senesni
leidimai gali negauti saugumo pataisų, suderinamumo atnaujinimų ar palaikymo.

## Kokios pagalbos galima tikėtis?

Nėra garantuoto atsakymo laiko, paslaugų lygio susitarimo (SLA) ar veikimo
garantijos. Projektas prižiūrimas tada, kai prižiūrėtojas turi laiko; priežiūra
gali būti pristabdyta ar nutraukta be išankstinio pranešimo.

[GitHub Issues](https://github.com/VooZ2/kinkudos/issues) tinka:

- pakartojamai KinKudos programos klaidai; arba
- aiškiai funkcijos idėjai.

Tai nėra bendra serverio administravimo ar hostingo pagalbos tarnyba. KinKudos
negali garantuoti pagalbos nestandartinėms Docker, NAS, reverse proxy, tinklo,
VPS ar operacinės sistemos konfigūracijoms.

Diegimo ir priežiūros klausimais pirmiausia perskaitykite [serverio
administravimo vadovą](../deployment-and-maintenance.lt.md) ir patikrinkite,
ar naudojate naujausią leidimą.

## Saugokite šeimos duomenis

Palaikymo prašyme ar GitHub Issue niekada nesiųskite slaptažodžių, API raktų,
SMTP ar saugyklos prisijungimo duomenų, duomenų bazės, atsarginių kopijų,
privačios šeimos informacijos, nuotraukų ar neredaguotų žurnalų.

Prieš pateikdami pakartojamą klaidą pašalinkite privačią informaciją. Jei
problemai paaiškinti reikia duomenų, kurių saugiai nuasmeninti nepavyksta,
neskelbkite jų viešame Issue.

## Pranešimas apie saugumo pažeidžiamumą

Apie nepataisytą saugumo pažeidžiamumą nekalbėkite viešame Issue. Vadovaukitės
privačiomis instrukcijomis repozitorijos
[saugumo politikoje](https://github.com/VooZ2/kinkudos/security/policy).
