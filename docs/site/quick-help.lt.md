# Greita pagalba

| Problema | Pirmiausia patikrinkite |
| --- | --- |
| Nerodomas vaiko profilis | Ar tai susietas vaiko įrenginys? |
| Vaikas negali prisijungti | Ar pasirinktas teisingas profilis ir įvestas teisingas PIN? Tėvai gali atrakinti laikinai užrakintą profilį. |
| Nėra darbo ar prizo | Patikrinkite būseną, vaiko tinkamumą ir ar paskirtas dienos darbas nepasibaigė. |
| Nepavyksta patvirtinti prizo | Patikrinkite vaiko balansą ir leistiną neigiamo balanso limitą. |
| Neateina pranešimai | Patikrinkite naršyklės leidimą; „iPhone“ ir „iPad“ įrenginiais KinKudos turi būti įdiegta į pradžios ekraną. |
| Namuose nebeveikia prieiga | Su administratoriumi patikrinkite esamus IP ribojimus; nespėliokite naujo leidžiamų adresų sąrašo. |
| Kopijai reikia dėmesio | Užsirašykite rodomą klaidą ir patikrinkite saugyklos ryšį bei prisijungimo duomenis. |

Apie pakartojamą programos klaidą praneškite programoje esančia atsiliepimų forma arba [sukurkite GitHub problemą](https://github.com/VooZ2/kinkudos/issues).
