# Your first 15 minutes

You need a parent account and one child device. Network, email, and backup settings can wait until the basic family flow works.

1. Open **Parents → Settings** and review the family name and point rules.
2. Create one child profile under **Family accounts and application settings**.
3. [Pair the child device](pair-a-child-device.md).
4. In **Tasks and rewards**, create two clear tasks and one attainable reward.
5. Submit a task from the child device, approve it from the parent area, then request and decide on one reward.
6. Confirm the activity appears in **Parents → History**.
