# Ein Kindergerät verbinden

Kinderprofil und Kindergerät sind verschieden. Das Profil enthält Name, PIN,
Regeln und Verlauf. Die Verbindung erlaubt einem bestimmten Browser, Smartphone,
Tablet oder einer installierten PWA, Profile anzuzeigen und eine Kinder-PIN zu
akzeptieren.

## Das aktuell verwendete Gerät verbinden

1. Melden Sie sich auf dem späteren Kindergerät als Elternteil an.
2. Öffnen Sie **Eltern → Einstellungen → Kindergeräte**.
3. Geben Sie einen eindeutigen **Gerätenamen** ein, etwa „Küchen-Tablet“.
4. Wählen Sie **Auf diesem Gerät zulassen**.
5. Melden Sie sich ab oder öffnen Sie die Kinderanmeldung. Das Kind kann sein Profil auswählen und die vierstellige PIN eingeben.

## Ein anderes Gerät über einen privaten Link verbinden

1. Öffnen Sie auf einem angemeldeten Elterngerät **Eltern → Einstellungen → Kindergeräte**.
2. Wählen Sie **Link senden**.
3. Übertragen Sie den Link privat auf das vorgesehene Gerät und öffnen Sie ihn dort. Veröffentlichen Sie ihn nicht in Gruppenchats oder gemeinsamen Notizen.
4. Der Link verbindet das Gerät einmal und läuft nach **10 Minuten** ab.

Nach der Verbindung zeigt KinKudos eine Bestätigung wie **Dieses Gerät ist als
Mac · Chrome verbunden**. Ohne eigenen Namen verwendet die Bestätigung und die
Geräteliste eine automatisch ermittelte, grobe Gerätebezeichnung.

## Verbundene Geräte verwalten

Die Liste zeigt ein grobes Gerätesymbol, einen optionalen eigenen Namen, eine
Zusammenfassung wie **iPhone · Safari** oder **Android-Tablet · Chrome**, eine
stabile sechs Zeichen lange ID und die letzte Nutzung. Die Einordnung umfasst Telefon,
Tablet, Computer und unbekanntes Gerät; ein exaktes Modell wird nicht versprochen.
Nach 30 Tagen ohne Nutzung erscheint zusätzlich **Lange nicht verwendet**.

Benennen Sie Einträge um, damit Sie sie erkennen. Widerrufen Sie den Zugriff
sofort, wenn ein Gerät verloren, verkauft oder dauerhaft verliehen wurde. Das
entfernt Kinderzugriff und Kinderbenachrichtigungen auf diesem Gerät, löscht aber
weder Profil noch Verlauf. Auf Mobilgeräten wird **Widerrufen** als kompakter
Papierkorb angezeigt.

Ein aktiv verwendetes verbundenes Gerät verlängert sein Zugriffscookie, damit
eine aktive Verbindung nicht stillschweigend abläuft. Ein Widerruf macht den
Zugriff sofort ungültig; das Gerät muss erneut verbunden werden.

Der Elternadministrator kann nach Eingabe des Passworts **Alle Kindergeräte
widerrufen**. Danach muss jeder Kinderbrowser beziehungsweise jede PWA erneut
verbunden werden.
