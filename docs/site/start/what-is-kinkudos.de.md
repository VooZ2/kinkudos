# Was ist KinKudos?

KinKudos ist eine private, selbst gehostete App für eine Familie. Kinder
erledigen Aufgaben, sammeln Punkte und fragen Belohnungen an. Eltern prüfen die
Anfragen und entscheiden über den nächsten Schritt.

Es gibt keine Werbung, keine integrierte Analyse und keinen öffentlichen
Familienbereich. Datenbank, Fotos und Zugangsdaten bleiben bei der Person, die
die Familieninstallation betreibt.

```text
Aufgabe → Einreichung → Entscheidung der Eltern → Punkte → Belohnung oder Ziel → Verlauf
```

## Die wichtigsten Funktionen

| Funktion | So funktioniert sie |
| --- | --- |
| **Aufgaben** | Kinder wählen eine Aufgabe aus dem Katalog und reichen sie optional mit Foto ein. Eltern genehmigen sie, bitten um Nachbesserung oder lehnen sie ab. |
| **Heutige Aufgaben** | Eltern weisen einem Kind Aufgaben für den Tag zu. Nach dem Abschluss werden die eingetragenen Punkte sofort gutgeschrieben. |
| **Belohnungen und Ziele** | Kinder fragen Belohnungen an oder schlagen neue Belohnungen und Sparziele vor. Eltern entscheiden und legen den endgültigen Punktepreis fest. |
| **Punkte und Verlauf** | Jede Gutschrift, Abbuchung, jedes Geschenk, Los und jede Korrektur erzeugt einen unveränderlichen Verlaufseintrag. |
| **Kredit** | Eltern können einen negativen Kontostand bis zu einer festgelegten Untergrenze erlauben. Neue Belohnungsanfragen werden pausiert, sobald die Hälfte des Kredits genutzt ist. |
| **Lose** | Ein optionales, von der Familie verwaltetes Rubbellos hat einen einstellbaren Preis, ein Wochenlimit und nachvollziehbare Ergebnisse. |
| **Kinderwelten** | Kinder wählen Designs und Avatare, aktivieren täglich zufällige Designs, ändern ihre PIN und schlagen Belohnungen oder Ziele vor. |
| **Benachrichtigungen** | Eltern und Kinder können Browser-Benachrichtigungen aktivieren. Auf iPhone und iPad muss die App zuerst zum Home-Bildschirm hinzugefügt werden. |

## Wer nutzt KinKudos?

- **Elternkonten** treffen Alltagsentscheidungen und sehen das Familien-Dashboard.
- **Elternadministratoren** verwalten zusätzlich sensible Einstellungen, Geräte und Sicherungen.
- **Kinderprofile** verwenden ein verbundenes Gerät und eine vierstellige PIN.
- **Serveradministratoren** betreiben Server, HTTPS, Updates und Wiederherstellung.

KinKudos ist keine Bank, kein Überwachungswerkzeug und kein soziales Netzwerk.
Es verfolgt weder den Standort eines Kindes noch liest es Geräteinhalte oder
private Nachrichten.
