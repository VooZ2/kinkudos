# Pair a child device

A child profile and a child device are different. The profile holds the child's name and PIN. Pairing authorizes one specific phone, tablet, or browser to show profiles and accept a child PIN.

Open **Parents → Settings → Child devices**, then choose one option:

- **Allow children on this device** when you are at that device.
- **Create private pairing link** when you need to open the link safely on another device. The link is single-use and expires quickly.

After pairing, choose the profile and enter the PIN on the child device. Revoke access immediately if the device is lost, sold, or no longer family-owned.
