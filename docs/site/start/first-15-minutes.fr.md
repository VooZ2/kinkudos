# Vos 15 premières minutes

Vous avez besoin d’un compte parent et d’un appareil enfant. Les règles réseau,
la messagerie et les sauvegardes distantes peuvent attendre que le fonctionnement
familial de base soit satisfaisant.

## Une première configuration fonctionnelle

1. Ouvrez **Parents → Réglages**. Donnez un nom à la famille et laissez les sections avancées inchangées pour le moment.
2. Sous **Comptes familiaux et réglages de l’application → Nouveau profil enfant**, créez un enfant. Choisissez un code PIN à quatre chiffres et une limite de crédit raisonnable, par exemple `-100` ou `0`.
3. [Associez l’appareil de l’enfant](pair-a-child-device.fr.md). Cette étape est obligatoire avant que l’appareil puisse afficher les profils enfants et accepter leur code PIN.
4. Dans **Parents → Tâches et récompenses**, créez deux tâches courtes et faciles à vérifier, puis attribuez-leur des points et un emoji.
5. Dans le même menu, créez une récompense accessible, par exemple « Choisir le dessert de ce soir ».
6. Sur l’appareil enfant, sélectionnez le profil, saisissez le code PIN, choisissez un thème et envoyez une tâche. N’ajoutez une photo que si elle facilite la vérification.
7. Dans **Parents → Accueil**, approuvez la tâche. Les points apparaissent sur la carte de l’enfant et dans l’historique.
8. Sur l’appareil enfant, demandez la récompense. Acceptez-la ou refusez-la dans le tableau de bord parent, puis vérifiez l’entrée d’historique.

La boucle essentielle fonctionne maintenant : action de l’enfant → décision du
parent → enregistrement visible et permanent.

## Ajouter le reste plus tard

- Configurez **SMTP** seulement si les parents ont besoin des e-mails de récupération de mot de passe ou de notification de retour.
- Configurez les **sauvegardes** distantes lorsque vous disposez d’un fournisseur de stockage et d’un endroit sûr pour le mot de passe du dépôt.
- Envisagez l’**accès réseau** uniquement si vous maîtrisez vos adresses domestiques ou VPN stables. C’est une protection supplémentaire, pas un prérequis.
