# Qu’est-ce que KinKudos ?

KinKudos est une application privée et auto-hébergée conçue pour une seule
famille. Les enfants accomplissent des tâches, gagnent des points et demandent
des récompenses ; les parents examinent les demandes et prennent les décisions.

Il n’y a ni publicité, ni analyse intégrée, ni espace familial public partagé.
La base de données, les photos et les identifiants restent sur votre propre
serveur.

```text
Tâche → soumission → décision du parent → points → récompense ou objectif → historique
```

## Fonctionnalités principales

| Fonction | Fonctionnement |
| --- | --- |
| **Tâches** | Les enfants choisissent une tâche du catalogue et l’envoient, éventuellement avec une photo. Les parents l’approuvent, demandent une correction ou la refusent. |
| **Tâches du jour** | Les parents attribuent des tâches pour la journée. Chaque tâche terminée ajoute immédiatement les points prévus. |
| **Récompenses et objectifs** | Les enfants demandent des récompenses ou proposent une récompense ou un objectif d’épargne. Les parents décident et fixent le coût final. |
| **Points et historique** | Chaque ajout, retrait, cadeau, ticket ou correction crée une entrée permanente dans l’historique. |
| **Crédit** | Un parent peut autoriser un solde négatif jusqu’à une limite choisie. Les nouvelles demandes de récompense sont suspendues lorsque la moitié du crédit est utilisée. |
| **Tickets de loterie** | Un ticket à gratter facultatif, contrôlé par la famille, possède un coût, une limite hebdomadaire et des résultats transparents. |
| **Univers de l’enfant** | Les enfants choisissent un thème et un avatar, activent un thème quotidien aléatoire, changent leur code PIN et proposent des récompenses ou objectifs. |
| **Notifications** | Parents et enfants peuvent activer les notifications du navigateur. Sur iPhone et iPad, l’application doit d’abord être ajoutée à l’écran d’accueil. |

## Qui l’utilise ?

- Les comptes **parents** prennent les décisions quotidiennes et voient le tableau de bord familial.
- L’**administrateur parent** gère aussi les réglages sensibles, les appareils et les sauvegardes.
- Les profils **enfants** utilisent un appareil associé et un code PIN à quatre chiffres.
- L’**administrateur serveur** gère le serveur, HTTPS, les mises à jour et la restauration.

KinKudos n’est ni une banque, ni un outil de surveillance parentale, ni un
réseau social. Il ne suit pas la localisation d’un enfant et ne lit ni le
contenu de l’appareil ni les messages privés.
