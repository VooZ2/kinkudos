# KinKudos convient-il à votre famille ?

KinKudos convient à une famille qui souhaite rendre les responsabilités du
quotidien visibles dans un espace privé partagé. Les parents définissent les
règles ; les enfants voient la prochaine étape, leurs progrès et leurs objectifs.

> **Pour :** Les parents qui évaluent KinKudos<br>
> **Prérequis :** Un membre de la famille ou une personne de confiance peut gérer le serveur<br>
> **Résultat :** Une décision claire avant l’installation

## KinKudos est adapté si…

- vous souhaitez gérer tâches, points, récompenses et décisions dans un espace familial privé ;
- quelqu’un peut maintenir une petite installation Linux/Docker ;
- les enfants peuvent utiliser un téléphone, une tablette ou un ordinateur contrôlé par la famille ;
- vous préférez définir vos propres règles familiales.

## KinKudos est peut-être inadapté si…

KinKudos n’est pas un service hébergé auquel il suffit de s’inscrire. Le projet
ne fournit ni serveur, ni domaine, ni service de messagerie ou de sauvegarde, ni
administrateur. Il n’existe aucune garantie d’assistance ou de délai de réponse
pour les configurations d’hébergement personnalisées.

Si personne ne peut gérer Docker, HTTPS, les mises à jour et les sauvegardes,
choisissez un outil familial géré ou demandez d’abord l’aide d’un administrateur
serveur de confiance.

## Ce que KinKudos ne décide pas

KinKudos ne décide pas quelles tâches sont équitables, combien vaut une
récompense ou si les tickets de loterie conviennent à votre famille. Les parents
fixent ces règles. La loterie facultative utilise uniquement les points internes
de la famille : ce n’est ni un achat ni un service de jeu d’argent externe.
