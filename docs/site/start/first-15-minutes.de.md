# Die ersten 15 Minuten

Sie benötigen ein Elternkonto und ein Kindergerät. Netzwerkregeln, E-Mail und
entfernte Sicherungen können warten, bis der grundlegende Familienablauf stimmt.

## Eine funktionierende Ersteinrichtung

1. Öffnen Sie **Eltern → Einstellungen**. Geben Sie der Familie einen Namen und lassen Sie die erweiterten Bereiche zunächst unverändert.
2. Erstellen Sie unter **Familienkonten und App-Einstellungen → Neues Kinderprofil** ein Kind. Wählen Sie eine vierstellige PIN und ein sinnvolles Kreditlimit wie `-100` oder `0`.
3. [Verbinden Sie das Kindergerät](pair-a-child-device.de.md). Erst dann kann das Gerät Kinderprofile anzeigen und eine Kinder-PIN akzeptieren.
4. Erstellen Sie unter **Eltern → Aufgaben und Belohnungen** zwei kurze, eindeutig prüfbare Aufgaben und legen Sie Punkte sowie ein Emoji fest.
5. Erstellen Sie im selben Menü eine erreichbare Belohnung, etwa „Heute das Dessert auswählen“.
6. Wählen Sie auf dem Kindergerät das Profil, geben Sie die PIN ein, wählen Sie ein Design und reichen Sie eine Aufgabe ein. Fügen Sie nur bei Bedarf ein Foto hinzu.
7. Genehmigen Sie die Aufgabe unter **Eltern → Startseite**. Die Punkte erscheinen auf der Kinderkarte und im Verlauf.
8. Fordern Sie auf dem Kindergerät die Belohnung an. Genehmigen oder verweigern Sie sie im Eltern-Dashboard und prüfen Sie den Verlaufseintrag.

Damit funktioniert der wichtigste Kreislauf: Aktion des Kindes → Entscheidung
der Eltern → sichtbarer, dauerhafter Eintrag.

## Später ergänzen

- Richten Sie **SMTP** erst ein, wenn Eltern E-Mails zur Passwortwiederherstellung oder zu Feedback benötigen.
- Richten Sie entfernte **Sicherungen** ein, sobald Speicheranbieter und ein sicherer Ort für das Repository-Passwort feststehen.
- Verwenden Sie **Netzwerkzugriff** nur, wenn Sie Ihre stabilen Heim- oder VPN-Adressen verstehen. Dies ist zusätzlicher Schutz, keine Voraussetzung.
