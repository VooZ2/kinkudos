# Quick help

| Problem | First check |
| --- | --- |
| A child profile is missing | Is this a paired child device? |
| A child cannot sign in | Is the correct profile selected and is the PIN correct? A parent can unlock a temporarily locked profile. |
| A task or reward is not visible | Check its status, child eligibility, and whether an assigned daily task has expired. |
| A reward cannot be approved | Check the child's balance and allowed negative balance floor. |
| Notifications do not arrive | Confirm notification permission and, on iPhone or iPad, that KinKudos is installed as a Home Screen app. |
| Access from home stopped working | Check existing IP restrictions with the administrator; do not guess at a new allowlist. |
| Backup needs attention | Record the displayed error and check the storage connection and credentials. |

For a reproducible software bug, use the in-app feedback form or [open a GitHub issue](https://github.com/VooZ2/kinkudos/issues).
