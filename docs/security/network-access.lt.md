# Tinklo prieiga

Tinklo prieiga yra pasirenkamas, tik administratoriui skirtas IP adresų leidžiamų sąrašas. Jis papildo tėvų slaptažodžius, vaikų PIN ir įrenginių susiejimą, bet jų nepakeičia.

- **Išjungta:** IP adresai neribojami.
- **Riboti vaikų prieigą:** vaikų puslapiai veikia tik iš įrašytų IP adresų ar tinklų, o tėvų sritis pagal IP neribojama.
- **Riboti visą prieigą:** tėvų ir vaikų puslapiai veikia tik iš įrašytų adresų ar tinklų.

> Prieš ribodami visą prieigą įtraukite formoje rodomą dabartinį IP adresą. Jei nežinote teisingo namų tinklo, pakeitimo nesaugokite.

Jei neteisinga taisyklė užrakina visus naudotojus, atkūrimas yra serverio administratoriaus veiksmas, aprašytas diegimo dokumentacijoje.
